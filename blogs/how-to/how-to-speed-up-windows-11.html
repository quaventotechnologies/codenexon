How to Speed Up Windows 11: 15 Proven Tips

Fifteen practical fixes for a slow Windows 11 PC, from startup programs and power settings to storage upgrades, no new hardware required for most of them.

Shubham Handore Published 09 Sep, 2026 ~6 min read

A slow Windows 11 PC is frustrating, but most performance problems come down to a handful of fixable causes. These proven tips will help you restore and improve performance without buying new hardware.

Quick answer: Disable unnecessary startup programs and check for malware first, these two fixes resolve most slowdowns. Then work through storage, power, and driver settings below.
In this guide:
  • 1. Startup Programs
  • 2. Storage Sense
  • 3. Power Settings

  • 5. Visual Effects

1. Disable Unnecessary Startup Programs

Press Ctrl+Shift+Esc to open Task Manager, go to the Startup Apps tab, and disable anything you don't need running the moment you log in. Every enabled startup app adds to your boot time and consumes memory in the background, this is consistently the single most effective fix for slow boot times.

2. Enable Storage Sense

Go to Settings > System > Storage > Storage Sense and turn it on. It automatically clears temporary files, empties the Recycle Bin on a schedule, and cleans up old Downloads folder files if you enable that option, freeing up disk space without manual maintenance.

3. Adjust Power Settings

Go to Settings > System > Power and set Power Mode to Best Performance when plugged in. Windows defaults to a balanced power profile that throttles CPU performance to save energy, which matters on battery but only holds your PC back when it's plugged into the wall.

4. Update Windows and Drivers

Outdated drivers, especially GPU drivers, are a common, easily overlooked cause of stuttering and poor performance. Keep everything current through Windows Update, and check your GPU manufacturer's site (NVIDIA, AMD, or Intel) directly for the latest driver, since Windows Update doesn't always ship the newest version.

5. Disable Unnecessary Visual Effects

Search for "Adjust the appearance and performance of Windows" in the Start menu and select "Adjust for best performance" to turn off animations, shadows, and transparency effects. On older or lower-spec hardware, these purely cosmetic effects can noticeably slow down everyday window management.

6. Run Disk Cleanup

Search for Disk Cleanup, run it as administrator, and select "Clean up system files" to remove old Windows Update files, temporary files, and previous Windows installation leftovers, these can easily add up to several gigabytes of dead weight over time.

7. Check for Malware

Unexplained slowdowns are sometimes a symptom of malware running in the background rather than a Windows configuration issue. If the tips above don't restore expected performance, run a full scan following our malware removal guide before assuming it's a hardware limitation.

8. Consider a Storage Upgrade

If your PC is still running on a traditional hard drive, upgrading to an SSD is the single biggest performance improvement available for older hardware, often more impactful than a CPU or RAM upgrade for everyday responsiveness like boot times and app launches.

More Quick Wins (9–15)

  • 9. Uninstall unused apps: via Settings > Apps, removing bloatware and abandoned software frees disk space and stops background processes you don't need.
  • 10. Turn off background apps: Settings > Apps > Installed apps lets you stop specific apps from running in the background when you're not using them.
  • 11. Disable search indexing on secondary drives: indexing every file on a large secondary drive can quietly consume disk and CPU resources for minimal benefit.
  • 12. Add more RAM if possible: 8GB is now the practical minimum for smooth multitasking; upgrading to 16GB is often the cheapest way to eliminate stutter under heavy use.
  • 13. Run System File Checker: open Command Prompt as administrator and run sfc /scannow to detect and repair corrupted system files that can cause slowdowns and crashes.
  • 14. Reduce transparency effects: Settings > Personalization > Colors > turn off transparency effects, which reduces GPU load on lower-end integrated graphics.
  • 15. Restart regularly: sleep mode is convenient, but a full restart clears memory leaks and temporary state that accumulate over days of uptime.

FAQs

Which single tip makes the biggest difference?
Disabling unnecessary startup programs, it's the most consistently effective fix for slow boot times and general sluggishness.

Will these tips work on Windows 10 too?
Most apply directly, though some settings menus are located slightly differently, the Task Manager startup tab and Disk Cleanup work identically on both.

Do I need to reinstall Windows if none of this helps?
Rarely, check for malware first (Tip 7), and consider a storage upgrade (Tip 8) before resorting to a full reinstall.
