Learn HTML and CSS from Scratch: A Beginners Complete Guide

A from-scratch introduction to HTML and CSS, covering structure, styling, key elements, and where to practice, no prior coding experience needed.

Shubham Handore Published 11 Sep, 2026 ~6 min read

HTML and CSS are the foundation of every website on the internet. This guide takes you from zero to building your first real web page, step by step.

Quick answer: HTML defines a page's structure and content; CSS defines how it looks. Learn HTML's tags first, then layer CSS styling on top, CodePen and freeCodeCamp are the fastest free starting points.
In this guide:
  • What is HTML?
  • What is CSS?
  • A Minimal Example
  • Key HTML Elements
  • Key CSS Concepts
  • Where to Practice
  • FAQs

What is HTML?

HTML (HyperText Markup Language) defines the structure and content of every web page, headings, paragraphs, links, images, and the containers that hold them together. It works using tags enclosed in angle brackets, most of which come in pairs: an opening tag like <p> and a closing tag like </p>, with your content sandwiched in between. Think of HTML as the skeleton of a page, it says what exists and in what order, but nothing about how it looks.

What is CSS?

CSS (Cascading Style Sheets) controls how those HTML elements actually look: colors, fonts, spacing, layout, and animations. Without CSS, every web page would render as plain black text on a white background in the order it appears in the HTML. CSS is what turns that raw structure into an actual designed page, positioning elements side by side, adding color schemes, and making a layout responsive across screen sizes.

A Minimal Example

A basic HTML page starts with a <!DOCTYPE html> declaration, followed by <html>, <head> (for metadata and stylesheet links), and <body> (for the visible content). Inside the body, a heading might look like <h1>Hello World</h1> and a paragraph like <p>This is my first page.</p>. CSS is linked in the head with a <link> tag pointing to a separate .css file, or written directly using a <style> block.

Key HTML Elements to Know

  • h1–h6: headings, from most important (h1) to least (h6).
  • p: paragraphs of text.
  • a: links, using the href attribute to point somewhere.
  • img: images, using the src attribute for the file path.
  • div and span: generic containers for grouping and styling content.
  • ul/ol and li: unordered and ordered lists, and their list items.

Key CSS Concepts to Know

  • Selectors: target which HTML elements a style applies to (by tag, class, or id).
  • The box model: every element is a box with content, padding, border, and margin.
  • Flexbox and Grid: the two modern layout systems for arranging elements on a page.

Where to Practice

CodePen.io lets you write and preview HTML and CSS directly in your browser with zero setup, ideal for quick experiments. freeCodeCamp.org offers a comprehensive, entirely free curriculum that walks through HTML and CSS fundamentals with hands-on projects. The fastest way to learn is to build something small and real, like a personal profile page, rather than only working through isolated exercises.

FAQs

Do I need to learn HTML before CSS?
Yes. CSS styles HTML elements, so you need at least basic HTML structure in place before styling makes sense.

How long does it take to learn the basics?
Most beginners can build a simple static page within a few days of focused practice; real fluency comes from building several small projects.

What should I learn after HTML and CSS?
